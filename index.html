A simpler workflow.

Log at your own pace

Type an answer and press Enter to save and advance. Option buttons submit immediately. True / False accepts T, F, True, or False. Text mode accepts any non-empty answer.

Press Backspace on an empty answer or ↑ to revisit the previous question. Esc closes dialogs. Overview lets you edit any answer.

Your file is your session

Finish & Save JSON includes your current typed answer. Load a saved file to choose Resume, Review, or Grade. Editing an answer clears its graded status, so you never see an outdated score.

Save into an /answers folder

Create an answers folder next to this index.html. In your browser's download settings, enable “Ask where to save each file before downloading,” then select that folder when you save. Browsers cannot silently write to a folder beside this page. Otherwise, files go to your default Downloads folder.

Private by design

Session files are read locally and never uploaded. Save before closing this tab; there is no automatic cloud or browser storage. Fonts and icons load from CDNs, but the app works without them.
